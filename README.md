# ttm2-project

Proyecto final del curso MAT2320 orientado al estudio teórico-práctico e implementación guiada del paper de referencia.
## Paper de referencia

Este proyecto toma como referencia principal el paper:

**Sophia Tang**, *A Complete Guide to Spherical Equivariant Graph Transformers*.

En este repositorio usamos el nombre corto **TTM2** para referirnos a este trabajo.

Referencia principal:
- arXiv: https://arxiv.org/abs/2512.13927v1
- autora: Sophia Tang

## Objetivo del proyecto

Desarrollar un análisis teórico-práctico de TTM2 con foco en:

- comprender en profundidad la arquitectura del paper,
- traducir sistemáticamente teoría y código,
- ejecutar el código base o una versión muy cercana,
- reimplementar un bloque central del modelo.

## Producto final acordado

Análisis teórico-práctico de TTM2 con ejecución del código base, traducción sistemática entre formulación matemática e implementación PyTorch/DGL, y reimplementación propia de un bloque central del modelo.
